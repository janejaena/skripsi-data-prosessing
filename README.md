# Thesis Data Processing and K-Means Clustering

## Project Overview
This repository contains the data processing and K-Means clustering implementation for academic thesis research.

The project uses transaction and product datasets to perform data preparation, feature engineering, clustering analysis, and cluster evaluation.

## Dataset
The project uses the following datasets:
- `Transactions.csv`
- `Products.csv`

Both datasets are stored in the `data/` directory.

## Methodology
The analysis includes:
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Feature engineering
4. Data standardization
5. K-Means clustering
6. Elbow Method evaluation
7. Silhouette Score evaluation
8. Cluster profiling and interpretation

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## How to Run
1. Open the Jupyter Notebook in this repository.
2. Open it using Google Colab.
3. Run all cells from beginning to end.
4. The datasets will be loaded directly from this GitHub repository.

No manual dataset upload is required.
